# ⛏️ เว็บไซต์พอร์ตโฟลิโอ & คอมมิชชันมายคราฟ (Minecraft Portfolio & Commissions)

เว็บไซต์สำหรับโชว์ตัวอย่างงานมายคราฟ (เช่น สกิน, โมเดล 3D, สิ่งก่อสร้าง) พร้อมระบุราคาข้างตัวอย่างงาน และสามารถเพิ่มผลงาน/หมวดหมู่ได้ด้วยตัวเองอย่างง่ายดาย

---

## ✨ ฟังก์ชันเด่น
1. **แสดงราคาข้างตัวอย่างงานชัดเจน**:
   - มีป้ายราคาเด่นชัดที่มุมตัวอย่างงานและรายละเอียดด้านล่าง
   - มีปุ่ม "สนใจสั่งทำ" ที่จะสร้างข้อความสรุปรายการพร้อมราคาให้ลูกค้าก๊อปปี้ไปสั่งทาง Discord หรือ Facebook ได้ทันที
2. **ระบบจัดการตัวอย่างงาน (ใส่เองได้)**:
   - อัปโหลดรูปสกินจากเครื่อง (PNG/JPG/WEBP) หรือใส่ลิงก์รูปภาพ
   - ตั้งชื่องาน, ราคา (฿), รายละเอียด, และแท็ก
   - รูปภาพแสดงผลแบบ Pixel-Art คมชัด ไม่เบลอ พร้อมพื้นหลังลายตารางแบบสกินแท้
   - คลิกเพื่อดูรูปขนาดเต็ม (Lightbox) ได้
3. **ระบบเพิ่ม/ลบหมวดหมู่ได้เอง**:
   - กดปุ่ม `+ เพิ่มหมวดหมู่ใหม่` ที่แถบหมวดหมู่เพื่อสร้างหมวดได้ตามต้องการ
   - ค้นหาและกรองผลงานตามหมวดหมู่ได้ทันที
4. **สลับโหมดใช้งานได้ 2 แบบ**:
   - **โหมดจัดการร้าน (Admin Mode)**: แสดงปุ่มเพิ่มผลงาน, แก้ไข, ลบ และตั้งค่า
   - **โหมดผู้ชม (Visitor Mode)**: ซ่อนปุ่มแอดมิน เพื่อให้ลูกค้าเห็นหน้าเว็บที่สะอาด สวยงาม สั่งทำง่าย

---

## 🚀 วิธีเปิดใช้งาน

1. เปิด PowerShell หรือ Command Prompt
2. เข้าโฟลเดอร์โปรเจกต์:
   ```powershell
   cd "C:\Users\WIN11\.gemini\antigravity\scratch\minecraft-portfolio"
   ```
3. เริ่มต้นรันเซิร์ฟเวอร์:
   ```powershell
   npm start
   ```
4. เปิดเบราว์เซอร์ไปที่:
   [http://localhost:3000](http://localhost:3000)

## 📁 โครงสร้างไฟล์
- `server.js` : ระบบหลังบ้าน Node.js + Express สำหรับบันทึกข้อมูลและอัปโหลดรูป
- `data/portfolio.json` : ไฟล์จัดเก็บข้อมูลผลงานและหมวดหมู่ (แก้ไขได้ บันทึกถาวร)
- `public/uploads/` : โฟลเดอร์เก็บไฟล์รูปภาพที่อัปโหลด
- `public/index.html` : หน้าเว็บหลัก
- `public/app.js` : โค้ด JavaScript จัดการระบบทั้งหมด
- `public/style.css` : ธีมสี Dark Cyber & Minecraft Emerald
